# CampusHub — frontend (React + Vite)

## Запуск на macOS / VS Code

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173

## Демонстрационный режим

Работает без backend: новости, категории, поиск, сортировка, вкладки подписок и рекомендаций, статьи и реакции, регистрация, вход, профиль, отправка публикаций и панель модератора. Данные хранятся в localStorage текущего браузера. Это **не настоящая серверная авторизация**; пароли демо-пользователей сохраняются локально, поэтому не используйте личные пароли.

Демо-аккаунт модератора:
- Email: `demo@campushub.ru`
- Пароль: `DemoPassword123!`

Созданные публикации попадают в очередь модерации. Войдите под модератором, чтобы одобрить или отклонить их. Данные демонстрационные и не отправляются на сервер.

Для сброса данных удалите ключ `campushub_demo_v2` из localStorage браузера.

## Подключение реального API позже

Создайте `.env` в папке frontend:

```env
VITE_DEMO_MODE=false
VITE_API_URL=http://localhost:8080/api/v1
```

Перезапустите `npm run dev`. API-адаптер в `src/api.js` сохраняет прежний сетевой режим и обработку refresh token. Демо-режим — временная замена источника данных.

## Структура

- `src/main.jsx` — страницы React и маршруты
- `src/style.css` — стили и фиолетовая тема
- `src/api.js` — API-клиент и переключатель демо-режима
- `src/demo.js` — локальные демонстрационные данные и операции
